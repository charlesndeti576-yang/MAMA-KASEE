MAMA Kasee V3
A mobile-friendly single-file website for MAMA POTATOES, built to run easily in Acode.
Features
MAMA POTATOES green logo
Fresh produce product cards with product pictures
Products:
Potatoes — KES 80/kg
Tomatoes — KES 80/kg
Butternut — KES 100/kg
Carrots — KES 100/kg
Cabbages — sold per size
Chilly — KES 120/kg
Bell Peppers — KES 80/kg
Product search
Stock status management
Shopping cart
Quantity controls
Automatic order total
WhatsApp ordering
Customer name, phone and delivery location fields
Business Manager for changing prices and stock status
Local storage for products and cart
Mobile-first responsive layout
Product imagery and green produce-themed background
WhatsApp Ordering
Orders are sent to the MAMA POTATOES WhatsApp business number configured in the HTML.
If the business number ever changes, edit the businessNumber value inside MAMA_POTATOES_V3.html.
How to Open in Acode
Open Acode.
Create or open your project folder.
Copy MAMA_POTATOES_V3.html into the folder.
Open the HTML file.
Use Acode's preview/browser option to launch the website.
Editing Prices
Open the Business section in the website.
You can change:
Product price
Stock status
The changes are saved on the device using browser local storage.
Important
This version is a front-end website and stores its product/cart data locally on the device. It does not yet use a remote database or server backend.
